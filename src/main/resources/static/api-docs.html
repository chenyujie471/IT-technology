        ▶请求参数说明
      

      

        

          
参数类型必填说明

          
            
modelstring必需模型 ID：claude-haiku-4-5-20251001 / claude-sonnet-4-6 / claude-opus-4-6 / claude-opus-4-7

            
messagesarray必需消息数组，每条含 role (user/assistant) 和 content

            
max_tokensinteger必需最大生成令牌数，建议 4096~128000

            
streamboolean可选是否流式输出，默认 false。推荐 true

            
systemstring可选系统提示词，设定 AI 角色

top_kinteger可选Top-K 采样

          
        

      


      
      

        ▶响应参数说明（非流式 stream=false）
      

      

        

          
参数类型说明

          
            
idstring消息唯一 ID，如 msg_01XFDUDYJgAACzvnptvVoYEL

            
typestring固定 "message"

            
rolestring固定 "assistant"

            
contentarray内容块数组，每项含 type("text") 和 text(回复文本)

            
modelstring实际使用的模型 ID

            
stop_reasonstring停止原因：end_turn / max_tokens / stop_sequence

            
stop_sequencestring|null触发停止的序列

            
usageobjectToken 用量

            
usage.input_tokensinteger输入消耗的 token 数

            
usage.output_tokensinteger输出消耗的 token 数

            
usage.cache_creation_input_tokensinteger缓存创建消耗 token

            
usage.cache_read_input_tokensinteger缓存读取消耗 token

          
        

      


      

        ▶响应参数说明（流式 stream=true，SSE 事件）
      

      

        

          
事件 type说明

          
            
message_start消息开始，包含 message 对象（id, model, usage 等）

            
content_block_start内容块开始，含 index 和 content_block（type, text）

            
ping心跳事件

            
content_block_delta增量内容，delta.text 为本次增量文本片段

            
content_block_stop内容块结束

            
message_delta消息级增量，含 stop_reason 和 usage

            
message_stop消息完成

参数类型必填说明

          
            
modelstring必需模型 ID：claude-haiku-4-5-20251001 / claude-sonnet-4-6 / claude-opus-4-6 / claude-opus-4-7

            
messagesarray必需消息数组，每条含 role (system/user/assistant) 和 content

            
max_tokensinteger可选最大生成令牌数，建议 4096~128000

        ▶响应参数说明（非流式 stream=false）
      

      

        

          
参数类型说明

          
            
idstring响应唯一 ID，如 chatcmpl-abc123

            
objectstring固定 "chat.completion"

            
createdintegerUnix 时间戳

            
modelstring实际使用的模型 ID

            
choicesarray回复选项数组

            
choices[].message.rolestring固定 "assistant"

            
choices[].message.contentstring回复文本内容

            
choices[].finish_reasonstring结束原因：stop / length / content_filter

            
usageobjectToken 用量

            
usage.prompt_tokensinteger输入消耗的 token 数

            
usage.completion_tokensinteger输出消耗的 token 数

            
usage.total_tokensinteger总 token 数

          
        

      


      

        ▶响应参数说明（流式 stream=true，SSE 事件）
      

      

        

          
字段说明

          
            
data: {...}每行一个 JSON chunk，object 为 "chat.completion.chunk"

            
choices[].delta.content本次增量文本片段

            
choices[].finish_reason流结束时给出，中途为 null

            
data: [DONE]流结束标记
